# Claude 账号管理工具

用于发布 Claude 账号管理工具安装包与使用说明，支持 Windows 与 macOS。

> 本仓库仅用于发布安装包与使用说明，不含源码。

## 下载

前往 [Releases](../../releases/latest) 页面下载最新版本。

| 系统 | 安装包 |
|---|---|
| Windows 10/11 (x64) | `Claude_账号管理工具_x.x.x_x64-setup.exe` |
| macOS (Apple 芯片 / Intel) | `Claude_账号管理工具_x.x.x_universal.dmg` |

## Windows 安装

1. 下载 Windows 安装包并双击运行。
2. 若出现 Microsoft Defender SmartScreen 提示，选择“更多信息”→“仍要运行”。
3. 安装完成后从开始菜单打开应用。

## macOS 安装

1. 打开 DMG，将应用拖入“应用程序”。
2. 首次打开若提示无法验证开发者，在“系统设置 → 隐私与安全性”中选择“仍要打开”。
3. 若系统提示应用已损坏，请先确认下载完整，再联系管理员处理。

## 更新说明

每个版本的功能与修复见对应 [Release](../../releases) 的发布说明。应用内“设置 → 检查更新”也可查看最新版本。
